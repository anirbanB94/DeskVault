# DeskVault

> Secure, Offline-First Enterprise Knowledge Platform powered by Local AI.

DeskVault is a modern desktop application built with **.NET 10** and **WinForms**, designed to demonstrate enterprise-grade architecture while delivering secure, offline AI-powered knowledge management.

Unlike cloud-dependent AI applications, DeskVault keeps documents, AI inference, and data processing entirely on the local machine using **Ollama** and **Phi-4 Mini**, making it suitable for environments where privacy, compliance, and offline capability are essential.
